# PERF-013 / PERF-014 — linear startup and unclean recovery

Proposed gates (ADR-0073), **off by default** until drain-inclusive measurements
are stable on CI hardware:

- **PERF-013**: `t_startup(65536) / t_startup(4096) <= 32` AND
  `t_startup(65536) <= 30s`, where `startup` is the full structural + historical
  evidence drain plus operational handoff (not merely `RedbStore::open`).
- **PERF-014**: unclean recovery wall time ≤ 3× clean startup at each checked
  checkpoint, where unclean recovery opens a file that exercised redb repair
  (kill-without-close of a writer process).

Enable with `--assert-perf-013` / `--assert-perf-014` on
`benchmarks/command-growth` after recording fresh JSONL evidence.

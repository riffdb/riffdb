# Typed native command-group construction admission

Package: WP-825. Tier: guarantee, within accepted native ownership and recovery
ceilings. No new format, dependency, application interface or larger limit.

Three original tests refused a legal 256-command group or its retained suffix
before decoding. The old allowance charged every nested wire message as both
the largest generated record and a whole semantic provenance record, even though
the containing capsule already owned those inline values. This was a conservative
estimate defect, not evidence that the actual decoder used that much memory.

Admission now counts each of the 59 reachable generated shapes at its actual
inline size and explicitly accounts for repeated semantic collection elements.
It retains the existing geometric-capacity and overlapping-graph factors, encoded
copies, canonical heap, prefix reconstruction, headers and scratch allowance.
Unbound reachable shapes refuse. Ordinary complete checksum, schema, canonicality,
manifest, source-binding and semantic validation still run after admission.

C3D checks: all three original reopen/crash/split tests pass, as do four native
ownership and dense-capacity controls, 13 proto shape/canonical/schema controls
and eight prefix/wire-version checks. Scoped proto/storage API/native all-target,
all-feature Clippy, allowed paths and file-size guards pass. A runner initially
expected five compatibility tests; its eight selected tests all passed. The
follow-up verifies their exact identities and finishes the remaining checks
without repeating successful original regressions.

Compatibility: bytes, durable group size, 64-MiB recovery window and 512-MiB native
aggregate ceiling are unchanged. The handbook startup page describes admission
and retained typed capacity refusal. Larger valid graphs may still refuse.
The decoded collection floor test is not a measurement of complete peak memory.
Hazards: final-source CI and shipping-profile workload checks remain required.
This does not fix close ownership, reconstruct pruned projection input, resolve
the original online-retention corruption or qualify either long campaign.

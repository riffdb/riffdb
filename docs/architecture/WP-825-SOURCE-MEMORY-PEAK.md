# WP-825 Source admission peak observation

Package: WP-825. Tier: guarantee under accepted ADR-0324. This internal
observation supports the actual combined worker memory qualification.

The existing accountant retains one numeric high-water value for aggregate
admitted memory, including its fixed control owner. Successful reservation
updates it; refused admission and reservation ownership transfers cannot
inflate it. Settlement and final physical release preserve the historical peak
while the existing live observation returns to its prior baseline.

The Source-only hidden getter reports this finite admission bound. It grants no
capacity, source selection or publication authority, and it is not an RSS
measurement. Foreign ledgers remain independent; poisoned or refused ownership
refuses observation. The existing fixed accountant size and all Source64 and
provider ceilings remain unchanged.

The focused proofs cover refused admission, simultaneous shared-handle work,
split/absorb transfers, settlement, final physical release and foreign/refused
accountants. A real TicketDesk batch with the private staging map, readers and
evaluator remains necessary before claiming combined worker capacity. This
change exposes no application or operator operation and changes no encoding,
fixture, query, authorization or command behavior.
